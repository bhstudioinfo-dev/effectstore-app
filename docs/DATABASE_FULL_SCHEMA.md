# Database Schema Specification

This document defines the fields, datatypes, indexes, and relationships of the MongoDB Mongoose models inside the EffectStore backend.

---

## 1. User Model (`User.js`)
Represents registered users, their active subscription tier, device licenses, and history.

- **`email`**: String (Required, Unique) - User's authentication email.
- **`password`**: String (Required) - Hashed password.
- **`name`**: String - Profile display name.
- **`phone`**: String (Required) - User's telephone contact.
- **`machineId`**: String - Currently locked local machine hardware UUID.
- **`subscription`**: String (Default: `'free'`) - Tier level: `'free'`, `'pro'`, `'business'`, `'studio'`.
- **`subscriptionExpiresAt`**: Date - Expiry timestamp of the current subscription level.
- **`activeDevices`**: Array of Strings - List of authorized hardware keys.
- **`purchasedEffects`**: Array of objects:
  - `effectId`: ObjectId (References: `Effect`) - Purchased effect.
  - `purchasedAt`: Date (Default: `now`) - Purchase date.
  - `licenseKey`: String - Unique license key generated for the purchase.
- **`totalSpent`**: Number (Default: `0`) - Total amount spent in VND.
- **`totalUses`**: Number (Default: `0`) - Cumulative count of effect triggers.
- **`isAdmin`**: Boolean (Default: `false`) - Grants access to admin management dashboard.
- **`isActive`**: Boolean (Default: `true`) - Status flag for active account status.
- **`createdAt`**: Date (Default: `now`) - Account creation timestamp.

---

## 2. Effect Model (`Effect.js`)
Represents visual effects (decrypted WebM overlay assets) available in the library.

- **`name`**: String (Required) - Display name.
- **`category`**: String (Required) - Category label.
- **`price`**: Number (Required) - Core cost.
- **`originalPrice`**: Number (Default: `0`) - Stated original price.
- **`discount`**: Number (Default: `0`) - Percentage discount.
- **`description`**: String - Detailed description.
- **`icon`**: String - File path to the preview icon.
- **`fileUrl`**: String - Path to the encrypted WebM asset on disk.
- **`previewUrl`**: String - Decrypted preview video path.
- **`thumbUrl`**: String - Path to preview thumbnail.
- **`duration`**: Number (Default: `15`) - Playback duration of the WebM file in seconds.
- **`encryptedFilePath`**: String - Absolute disk path of the AES-256 encrypted source file.
- **`fileSize`**: Number - Size of the asset in bytes.
- **`rating`**: Number (Default: `5.0`) - Average rating.
- **`uses`**: Number (Default: `0`) - Total trigger counts.
- **`isActive`**: Boolean (Default: `true`) - Visibility flag.
- **`isTrending`**: Boolean (Default: `false`) - Trending flag.
- **`isFlashSale`**: Boolean (Default: `false`) - Flash sale flag.
- **`flashSalePrice`**: Number (Default: `0`) - Promo price.
- **`flashSaleEndsAt`**: Date - Expiry of the promo price.
- **`timeline`**: Object (Default: `{}`) - Contains timestamps of visual cues.
- **`isComposite`**: Boolean (Default: `false`) - True if combining multiple media layers.
- **`createdAt`**: Date (Default: `now`) - Creation timestamp.

---

## 3. Gift Menu Layout Model (`GiftMenuLayout.js`)
Stores the customized widget designs, positions, and coordinates generated by the Menu Designer.

- **`userId`**: ObjectId (References: `User`, Optional) - Owner of the layout.
- **`name`**: String (Required) - Layout name.
- **`aspectRatio`**: String (Default: `'9:16'`) - Bounding resolution mode: `'9:16'`, `'16:9'`, `'1:1'`.
- **`items`**: Array (Default: `[]`) - Collection of JSON layouts configured in the app canvas (x, y, w, h, scale, rotation, details).
- **`exportedItems`**: Array (Default: `[]`) - Pre-rendered responsive JSON elements served to the OBS Browser Source.
- **`isActive`**: Boolean (Default: `false`) - Layout status flag.
- **`isTemplate`**: Boolean (Default: `false`) - Available as a baseline template.
- **`category`**: String (Default: `'all'`) - Filtering category.
- **`timestamps`**: Generated automatically by Mongoose (createdAt, updatedAt).

---

## 4. Gift Mapping Model (`GiftMapping.js`)
Maps incoming TikTok gift triggers to designated overlay video effects.

- **`userId`**: String - Unique owner ID.
- **`sessionId`**: String - Streaming session token.
- **`giftId`**: String (Required) - TikTok gift code.
- **`giftName`**: String - Gift display label.
- **`giftIcon`**: String - URL to the gift icon.
- **`effectId`**: ObjectId (References: `Effect`, Required) - Designated video effect.
- **`effectName`**: String - Effect name.
- **`isActive`**: Boolean (Default: `true`) - Active flag.
- **`createdAt`**: Date (Default: `now`) - Mapping creation date.
- **`updatedAt`**: Date (Default: `now`) - Mapping edit date.
